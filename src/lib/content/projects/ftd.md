## Overview

FTD is a 2D, top-down factory-building and tower-defense game created by a four-person team as a senior design project. It combines a nine-level single-player campaign with the challenge of placing buildings, producing items, shooting enemies, and defending a base.

Factory layouts rely on conveyor-belt logistics, while buildings consume resources and towers require ammunition. With limited space, each level asks players to balance production, defense, and where to place the next structure.

## Technical notes

The game was built with Java and libGDX, with the repository’s MVC structure separating game state, application control, and rendering. Its factory systems, tower defenses, and nine-level campaign were designed to work together as one playable production-and-defense loop.
